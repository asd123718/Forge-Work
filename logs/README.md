# Forge Logs

This directory stores runtime logs generated by Forge. Model output logs are written under `logs/models/`.

## Layout

```
logs/
  models/
    2026-08-27_14-30-00_ab12cd34/
      index.md                 # run overview + links to every entry
      001-leader-plan-codex.md # leader planning turn
      002-worker-codex-task.md # worker execution turn
      003-leader-review-codex.md
```

Each Markdown entry includes:

- **Thinking** — reasoning / streaming progress from the model
- **Tool Calls** — tool name, status, input, and output when available
- **Output** — final model response body
- **Command Execution** — CLI worker commands and streamed stdout/stderr

## Configuration

By default, logs are written to `<repo-root>/logs/models`.

Override the location with the environment variable:

```
FORGE_MODEL_LOG_DIR=C:\path\to\your\logs
```

`start-forge.cmd` and `start-forge.exe` set this automatically to the repository `logs\models` folder on Windows.
